Install in one command.

The installer downloads ElevenVoice, sets up Bun and uv if you don't have them, picks the right engine for your GPU and opens the app.

PS> irm https://raw.githubusercontent.com/Hylanderry/ElevenVoice/main/install.ps1 | iex
$ curl -fsSL https://raw.githubusercontent.com/Hylanderry/ElevenVoice/main/install.sh | sh

Prefer to do it by hand? Manual steps on GitHub. Desktop installers are on the way.

Questions.

Is it really free?

Yes. There are no plans, credits or sign-in. The code is open source under the AGPL-3.0.

What computer do I need?

Windows 10/11, macOS on Apple Silicon or a 64-bit Linux, with 16 GB of RAM recommended. The default voice engine wants a GPU with about 6 GB of memory; lighter engines run on any computer.

Can I use the voices commercially?

The app is free for any use, but each voice model has its own licence. The default engine (OmniVoice) is for personal and research use. Check every model's notice in Settings → Models before paid work, and only clone voices you have permission to use.

Does anything leave my computer?

No. Models download once from Hugging Face; after that everything runs offline. Online translators are optional and only used if you add your own keys.
